# Tài nguyên giao diện Vinmec

- Logo: ảnh do người dùng cung cấp tại `Biểu tượng VINMEC vàng xanh tinh tế.png`, được sao chép nguyên bản vào `vinmec-logo.png`.
- Font: Inter variable 100–900, bản Latin và tiếng Việt, dùng đúng các file WOFF2 được trang tham chiếu tải từ Google Fonts.
- Giao diện dùng bộ token VINMEC được người dùng cung cấp trong `workspace-tokens.css`; sắc xanh chức năng đậm hơn được dùng khi cần đáp ứng tương phản.

Tài nguyên giao diện được lưu cục bộ để không cần tải font hoặc logo từ website ngoài. Giao diện dùng nền tối trung tính riêng cho việc đọc ảnh.
