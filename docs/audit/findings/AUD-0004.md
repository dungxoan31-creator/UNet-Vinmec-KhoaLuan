- **Impact Analysis**: Không ảnh hưởng tới người dùng cuối hay logic hiển thị UI (giao diện thực tế hiển thị cả 2 bảng rất đẹp và trực quan). Đây là lỗi viết test script tự động chưa chỉ định cụ thể phần tử cần đợi khi UI mở rộng thêm bảng dữ liệu split.
