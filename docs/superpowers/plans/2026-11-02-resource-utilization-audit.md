# Resource utilization audit and integration

## Scope and checkpoints

Preserve the existing dirty worktree. Audit production, research, evaluation,
dependencies and UI independently; source reachability is not runtime proof.

1. Capture source inventory and run the existing Python and JavaScript baselines.
2. Trace unused/duplicated services to their actual API/UI entry points. Classify
   source-connected resources separately from runtime-verified capabilities.
3. Consolidate the duplicated classifier onto the existing hash-verified,
   training-parity implementation. Remove duplicate inference, random-weight
   fallback and unsupported physical measurements. Keep segmentation 512×512,
   clinician review, and research-only classification.
4. Reuse source-coordinate mask/caliper utilities; verify non-square geometry,
   abstention, missing checkpoints, API persistence and reopening.
5. Inspect the viewer and streamline only proven repetitive interactions. Run
   JavaScript checks, Python regressions, real API browser E2E and desktop GUI
   inspection. Record failures, skips and mocks explicitly.
6. Publish a resource matrix and evidence report, with validation/data blockers.

## Acceptance limits

No new model or preprocessing default without comparative validation. No clinical
accuracy claim from synthetic tests or validation-set model selection. Image-level
splits must remain SHA-256 deduplicated; patient independence remains unverified.
No activation of foundation-model adapters without verified weights and evaluation.
No assumption that passing syntax checks constitutes a frontend build/type check.
