**Goal:** Implement the v2.1 multi-branch ultrasound AI architecture (Branches A, B, C, D) and "AI-first one-touch review" pipeline in `UNet-Vinmec-KhoaLuan`, including watershed follicle separation, autonomous diagnostic reasoning with fail-closed abstain logic, CDSS integration, and active learning override capture.

**Architecture:** A 4-branch pipeline (Ovary, Follicles, Lesions, Diagnostic Reasoning) built on top of the modular FastAPI/PyTorch backend. Morphology extractor adds distance-transform watershed follicle separation; a dedicated `DiagnosticReasoningEngine` auto-estimates O-RADS features and classifies lesions (MMOTU 8-class); these findings auto-populate `CDSSReasoningEngine` without clinician manual entry; the review service records one-touch confirmations and saves modifications into an active learning feedback queue.

**Tech Stack:** Python 3.12, FastAPI, PyTorch, Pydantic v2, OpenCV, scikit-image (`skimage.segmentation.watershed`), SciPy (`scipy.ndimage`), ReportLab, pytest.

## Global Constraints

- **Synthetic Test Fixtures Only:** All automated unit and integration tests must generate synthetic image fixtures in `tmp_path` and MUST NOT read raw images from `dataset/` or `ai_training/` (Enforced by `QA-TEST-SYNTHETIC-001`).
- **Letterbox 512×512 Standard:** All image and mask tensors follow Letterbox aspect-ratio preserving 512×512 geometry with CLAHE enhancement.
- **Fail-Closed & Abstain Protocol:** Features that cannot be extracted from 2D B-mode (Doppler, ascites) must be marked `unavailable`. If top-1 confidence < 0.60, top-2 margin < 0.15, or image is OOD, the engine must set `abstain: True` and refer to clinician without guessing.
- **Physiological Follicle Policy:** Follicles < 30 mm are physiological and mapped to O-RADS 1.
- **Pydantic v2 Compatibility:** All schemas use `ConfigDict`, `field_validator`, and strict typing without deprecated Pydantic v1 methods.

## Review Focus

1. **Overlapping Follicle Segmentation:** Ensure watershed separation correctly splits touching spherical/elliptical follicles without over-segmenting smooth solitary follicles.
2. **Abstain / Refusal Behavior:** Ensure borderline probabilities or unconfident classification trigger `abstain: True` with informative Vietnamese explanations.
3. **CDSS Automatic Feature Ingestion:** Ensure `CDSSReasoningEngine` receives AI-estimated descriptors without requiring manual doctor input, but marks `complete: False` if Doppler is unavailable.
4. **Active Learning Feedback Integrity:** Ensure clinician overrides in review requests are validated, immutably logged, and written to the active learning queue without corrupting existing review records.
5. **No Regressions on Existing Benchmarks:** Ensure all 115+ existing tests in `tests/` continue to pass.
